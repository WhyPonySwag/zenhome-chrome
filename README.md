# ZenHome 0.2 — Matte Black Refinement

Локальная стартовая страница для настольного Google Chrome на Windows 11. Вкладка называется «Новая вкладка». В центре расположены часы, дата и поиск, ниже — восемь колонок быстрых ссылок и два виджета. Страница использует системный шрифт и запускается без сборки.

Нейтральный акцент применяется при первом открытии и после подтверждённого сброса. Если в браузере уже сохранён цвет, страница использует его.

## Запуск в Windows

Откройте PowerShell в папке ZenHome и запустите сервер стандартной библиотеки Python.

```powershell
py -3.13 -m http.server 8765 --bind 127.0.0.1
```

Если команда `py` отсутствует, используйте доступный Python 3 через `python` или полный путь к `python.exe`. Для среды Codex на этом компьютере проверена команда:

```powershell
& "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" -m http.server 8765 --bind 127.0.0.1
```

Откройте [локальную страницу ZenHome](http://127.0.0.1:8765/). Сервер раздаёт файлы только на этом компьютере. Запущенный в терминале сервер можно остановить сочетанием Ctrl+C. Используйте один и тот же адрес и порт, чтобы браузер видел сохранённые настройки. Страница использует ES-модули и рассчитана на открытие по HTTP.

## Управление

- Введите запрос или адрес и нажмите Enter. Список справа переключает Google, Яндекс и Bing. Для сайтов допустимы HTTP и HTTPS, домен без схемы открывается по HTTPS.
- Клавиша `/` переводит фокус в поиск. Escape в поле поиска очищает его. Клавиша запятой вне поля ввода открывает настройки. Escape закрывает верхнее диалоговое окно.
- Кнопка «Добавить» создаёт ссылку. Через «Изменить» можно поменять название или адрес, удалить ссылку и переместить её выше или ниже. В том же порядке ссылки расположены на стартовой странице.
- Настройки открываются шестерёнкой в правом верхнем углу. В них доступны имя, приветствие, часы, поисковик, виджеты, акцент, интенсивность стекла и управление ссылками. Изменения сохраняются сразу. Восстановление стандартных настроек возвращает исходные 16 ссылок и город после подтверждения.
- В переводчике кнопка EN ⇄ RU меняет направление. «Перевести» открывает Google Translate в новой вкладке с введённым текстом.
- Время и приветствие используют часовой пояс браузера. Дата отображается на русском языке.

## Погода и локальные данные

Город по умолчанию — Севастополь. Нажмите название города, введите новое и выберите результат с нужным регионом. Данные о населённых пунктах предоставляет GeoNames через [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api).

Погода включает текущую температуру и условия, суточный минимум и максимум, ветер в м/с. Виджет сохраняет последний ответ вместе с координатами и временем получения. При повторном открытии в течение 30 минут использует кэш. В случае сбоя показывает данные выбранного города с отметкой времени или сообщение о недоступности. Кнопка обновления повторяет запрос вручную. Скрытый виджет и скрытая вкладка приостанавливают обновления.

Источник модельных погодных данных — [Open-Meteo Forecast API](https://open-meteo.com/en/docs). Температуры округляются для отображения, коды условий переведены на русский. Данные распространяются по [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Бесплатный API рассчитан на личное некоммерческое использование с лимитами запросов. [Условия Open-Meteo](https://open-meteo.com/en/terms)

Настройки, ссылки и погода хранятся в LocalStorage этого браузера под префиксом `zenhome.v1.`. При недоступном хранилище персонализация действует в текущей вкладке. Единственные автоматические внешние запросы страницы связаны с видимым погодным виджетом. Иконки загружаются локально, шрифт берётся из системы.

## Структура

- `index.html` — страница и диалоговые окна.
- `css/styles.css` — матовые поверхности, настольная сетка и отступы для окон разной высоты.
- `js/app.js` — часы, поиск, ссылки, персонализация и управление с клавиатуры.
- `js/storage.js` — настройки по умолчанию, проверка адресов и чтение LocalStorage.
- `js/weather.js` — запросы прогноза и геокодирования, кэш и обработка ошибок.
- `assets/icons/` — иконки интерфейса и сервисов. [Источники значков](assets/icons/README.md)

Код интерфейса размещён во внешних модулях. Для будущей версии Chrome Manifest V3 понадобятся манифест с назначением новой вкладки и настройка доступа к погодному сервису.
