# Значки быстрых ссылок

Имена и товарные знаки принадлежат владельцам соответствующих сервисов. ZenHome хранит копии значков локально.

- ChatGPT, Claude, Gemini и DeepSeek взяты из набора [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons). Лицензия MIT приведена ниже.
- YouTube, SoundCloud, Spotify, FACEIT, GitHub, Vercel, VirusTotal, Telegram, Twitch и Pinterest взяты из [Simple Icons 13.0.0](https://github.com/simple-icons/simple-icons/tree/13.0.0/icons). Набор распространяется по [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/13.0.0/LICENSE.md).
- Компактный знак CYBERSHOKE взят из [официального брендбука](https://cybershoke.net/Brand).

Знак Figma воспроизведён в пяти фирменных цветах.
